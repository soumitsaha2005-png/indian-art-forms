# Kala Dharohar — The Living Heritage of Indian Art Forms 🎨✨

An interactive and immersive web exploration showcasing the timeless beauty, history, techniques, and cultural significance of traditional Indian folk and classical art forms.

---

## 🌟 Featured Art Forms

- **Madhubani (Mithila Art)** — Ancient folk art from Bihar depicting mythological themes and nature with vibrant natural dyes.
- **Warli Painting** — Tribal rhythmic art from Maharashtra celebrating community, nature, and circle of life.
- **Tanjore Painting** — Rich South Indian art from Tamil Nadu known for vivid colors, iconic gold foil (thattodu), and semi-precious stones.
- **Kalighat Painting** — 19th-century Bengal school of art featuring expressive brushstrokes and social commentary.
- **Pattachitra** — Cloth-based scroll painting from Odisha with intricate narratives and mythological motifs.
- **Kolam** — Sacred geometric threshold art from South India drawn daily with rice powder symbolizing prosperity and harmony.

---

## 🚀 Features

- **Interactive Map**: Geographical exploration of traditional art forms across India using Leaflet.
- **Deep-Dive Visual Galleries**: High-resolution imagery, historical context, pigment recipes, and motif symbolism.
- **Responsive & Modern UI**: Rich dark-mode aesthetic with smooth typography, animations, and micro-interactions.
- **Interactive Quizzes & Exploration**: Engage with cultural stories and test your knowledge.

## 💻 Getting Started

Simply open `index.html` in any modern web browser to explore the project.

```bash
# Clone the repository
git clone https://github.com/soumitsaha2005-png/indian-art-forms.git

# Navigate to project directory
cd indian-art-forms

# Open index.html
start index.html  # Windows
open index.html   # macOS
```
